### 6. 🔵 Thevenin's Theorem

- [ ] Thevenin Resistance (RTH)
- [ ] Open Circuit Voltage
- [ ] Short Circuit Concept
- [ ] Equivalent Circuit
- [ ] Load Current
- [ ] Solved Examples
- [ ] Numerical Problems

### Formula

```text
IL = VTH / (RTH + RL)
```

### Where

```text
VTH = Thevenin Voltage
RTH = Thevenin Resistance
RL  = Load Resistance
IL  = Load Current
```

# ⚡ Quick Revision

### Ohm's Law

```text
V = IR
I = V/R
R = V/I
```

### Power

```text
P = VI
P = I²R
P = V²/R
```

### KCL

```text
ΣIin = ΣIout
```

### KVL

```text
ΣV = 0
```

### Thevenin

```text
VTH = VOC
RTH = Equivalent Resistance
```

### Norton

```text
IN = ISC
RN = RTH
```

### Maximum Power Transfer

```text
RL = RTH
```
